# homepage_tachikawa_3 — 大木の町 M2D TOWN（3D ジオラマ版）

ホームページコンペ応募作（立川）の第 3 案。トップページに **傘のように広がる一本の大木を中心にした小さな町** の 3D 模型を置き、文章をその上に重ねる構成。
季節（春: 桜 / 夏: 広葉樹 / 秋: 紅葉 / 冬: 雪の裸木）はメニューの「季節」で切り替えられ、初期値は今日の日付から決まる。花びら・落ち葉・雪が舞う。
配色は「黄・紺・緑・黒」の 4 案を右上の色の丸で切り替えられる（選択はブラウザに記憶）。最上部では模型が右側で自転し、1 画面分スクロールすると中央に来てドラッグで回せる。模型上の ● を押すと各ページへ飛ぶ。

## 構成

| パス | 内容 |
|---|---|
| `src/pages/index.astro` | トップ。固定表示の 3D キャンバスの上に、見出し・研究テーマ・お知らせ・数字・連絡先の各節を重ねる |
| `src/scripts/diorama.js` | three.js の 3D シーン。芝生の広場と環状の道、大木（幹・枝は固定、樹冠と雪は季節で生成）、季節の粒子、研究棟・講義棟・食堂・売店、木、研究者、キャッチボールの 2 人、旋回する飛行機、電子顕微鏡、立て看板、郵便受け、M2D の文字。季節は先頭の `SEASONS`、配色は `THEMES` で調整 |
| `src/components/SiteChrome.astro` | 共通の上部バー（ハンバーガー・ロゴ・配色）と、左から出るナビのモーダル |
| `src/layouts/Base.astro`, `src/scripts/transitions.ts` | 文章ページの共通レイアウトと flipX のページ切替（Astro View Transitions） |
| `public/style.css` | ページの見た目。`:root[data-theme="yellow|black"]` で配色を切替 |
| その他のページ | トップと同じ配色・ナビ・パネル表示に統一 |

- 3D は [three.js](https://threejs.org/)（MIT ライセンス）を npm で導入。モデルファイルや画像は使わず、すべてコードで組んでいる。
- マウスの動きで模型が傾き、スクロールでゆっくり回る。`prefers-reduced-motion` が有効な環境では動きを止める。
- 立方体の数は約 4,000 個を 1 つの InstancedMesh にまとめており、スマートフォンでも動く想定（要実機確認）。
